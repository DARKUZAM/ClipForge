LOCAL-FIRST CAPTURE

Only the moments.
No full stream recording.

For live broadcasts, ClipForge reads available chat history from the stream start and keeps a short rolling video buffer. When it finds a chat spike, it saves that moment. Older spike windows are fetched as short sections only.

Local AI analyzes the chat and sample frame on this PC. API mode sends the selected chat excerpt and frame to your configured provider.

Local Whisper creates word timed captions; install it in AI Settings if captions are unavailable. Captions and animated emojis are burned into the clip with your font, size, color, and position settings. Auto layout stacks a detected webcam above gameplay.
